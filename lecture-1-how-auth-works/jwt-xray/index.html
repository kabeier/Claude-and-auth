JWT X-ray

Paste an access token (it starts with eyJ) to see its three parts. Everything happens in this page; the token is never sent anywhere.

Signature

        
Made by Supabase with a key only it has. Change one letter of the header or payload and this no longer matches: Supabase answers 401.

        

      

    

    
Never put secrets in a payload (passwords, card numbers): it's base64, which anyone can decode, as this page just did.
