-- the trigger: auth.users → public.users
create trigger on_auth_user_created
  after insert on auth.users
  for each row
  execute function public.handle_new_user();

-- every task gets its owner from the token
user_id uuid not null default auth.uid()
-- the curriculum's policy
create policy "Users can view own tasks"
  on tasks
  for select
  to authenticated
  using (auth.uid() = user_id);

-- + insert, update, delete:
-- the same check

The app never sends a user id. The token does.

While Claude works. Compare these with what Claude actually shows you: names will differ, the ideas shouldn't.

  • Trigger: handle_new_user is security definer: it runs as the database owner, because the new user can't insert into public.users yet.
  • default auth.uid(): the database fills in the owner from the token. On Friday the app had to send the Demo User's id; now it can't lie about who it is.
  • Policy: "for each row: does the id in your token match this row's user_id?" to authenticated = anon gets nothing.
